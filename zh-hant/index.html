緯線：我們的原則

  • 先問要完成什麼，再談功能。

    人打開 App，是想把某件事往前推。把這件事說準了，其餘自然水到渠成。

  • 為那一刻設計，不只為螢幕。

    人用 App 的時候，可能正擠在車廂裡，單手拿著手機，心思一半在別處。我們為那一刻設計，手機只是把它送到人手上的方式。

  • 平靜，是設計出來的。

    每個畫面只有一個主要動作、一個強調色，沒有東西在大聲叫嚷。介面平靜，才贏得信任。

經線：我們的專業

  • 產品策略

    界定問題、找準對象，看清哪一注值得下。

  • 研究

    和人聊、讀懂市場，知道下一個該問什麼。

  • 互動設計

    流程、狀態，還有大多數團隊上線後才撞見的邊緣情況。

  • 品牌識別與設計系統

    從標誌、動態到整套介面規範，讓產品由裡到外渾然一體。

  • 工程開發

    用 React Native 打造 iPhone 和 Android App，做工和設計一樣講究。
